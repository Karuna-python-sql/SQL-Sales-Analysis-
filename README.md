# ==== SQL Sales Analysis Project 

# ===== Project Overview ======== 

SQL Sales Analysis is a database project developed Using MYSQL 8.0 to analyze customer information, Product sales, order details and business revenue.

# MYSQL 8.0 
# SQL 
# GitHUB 
# VS CODE/MYSQL Workbench

# Customers 
# Products

# INNER JOIN and LEFT JOIN
